# OneClick Dokumenten-Assistent

Web-App zum Verwalten und Verarbeiten von Dokumenten mit KI-Unterstützung.

## Technologie

React 19 · TanStack Start · Vite · Tailwind CSS 4 · Supabase (Auth/Daten) · pdf-lib & pdfjs-dist (PDF-Verarbeitung)

## Lokal starten

```bash
npm install
npm run dev
```

E2E-Tests: `npm run test:e2e` (Playwright)

## Hinweis

Dieses Projekt ist mit [Lovable](https://lovable.dev) verbunden – Git-Historie nicht umschreiben (siehe `AGENTS.md`). Konfiguration über `.env`.
